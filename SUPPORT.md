# Support

## Getting Help

### GitHub Issues
- **Bug reports**: Use the Bug Report template in `.github/ISSUE_TEMPLATE/bug_report.md`
- **Feature requests**: Use the Feature Request template in `.github/ISSUE_TEMPLATE/feature_request.md`
- **Questions**: Open a regular issue with the `question` label

### Documentation
- [README.md](./README.md) — Project overview, setup, and architecture
- [CONTRIBUTING.md](./CONTRIBUTING.md) — Contribution guidelines
- [SECURITY.md](./SECURITY.md) — Security vulnerability reporting
- `docs/` directory — Architecture, production guide, backup/recovery, Windows installation
- [CHANGELOG.md](./CHANGELOG.md) — Version history

### Internal Support
For MINDUS internal team members, contact the development team through official channels.
